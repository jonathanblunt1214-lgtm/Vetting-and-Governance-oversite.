# Vetting and Governance Oversight

Independent, non-assimilating 24/7 oversight for the complete registered Crucible organism. Every five minutes it vets bounded data manifests and audits every registered component from outside its runtime; it contains no product code and grants Crucible no write authority. Candidate-only Worker snapshots are accepted through a separate encrypted, commit-bound branch, checked against the exact current vetted-state lineage and original independently vetted source hashes, and republished only by oversight. Report archival and vetted-state publication do not depend on GitHub Actions artifact quota. It can order an immediate fail-closed stop, but never learns from inspected data. See `OVERSIGHT-POLICY.md`.
